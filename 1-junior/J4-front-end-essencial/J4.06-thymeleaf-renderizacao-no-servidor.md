# J4.06 — Thymeleaf: renderização no servidor

> ⏱️ ~1h30 · 🟢 Júnior · Pré-requisitos: J4.01 a J4.05, J2.06 (servidor HTTP mínimo), J3.11 (JDBC), J2.04 (cookies e sessão)

## 🎯 Objetivos
Ao final desta aula você consegue:
- Explicar a diferença entre **renderização no servidor** (SSR) e uma página que se monta no navegador com JavaScript.
- Usar o **Thymeleaf** para transformar um protótipo HTML em **template** (`th:text`, `th:each`, `th:if`, `th:href`, `th:action`, `th:classappend`, fragmentos).
- Explicar o **escape automático** de HTML (`th:text`) e o risco de `th:utext`.
- Montar o **painel do PayFlow** (login, contas, extrato, depósito) com o servidor JDK da J2.06, os repositórios JDBC da J3 e sessão por cookie.
- Aplicar o padrão **Post/Redirect/Get** e responder com os códigos HTTP certos (303, 400, 401, 404, 422).

## 🤔 Por que isso importa
Muitas aplicações Java corporativas entregam páginas **prontas do servidor**: o Spring MVC com Thymeleaf é uma das combinações mais comuns em vagas de back-end e full stack. O servidor busca os dados, preenche um modelo de HTML e responde com a página completa; o navegador só exibe. Isso dá páginas rápidas de abrir, funciona **sem JavaScript**, é simples de proteger (a regra fica no servidor) e é bom para SEO. Entender o mecanismo **sem a mágica do Spring** (que entra na J5) faz o `Model`, o `@Controller` e o `return "statement"` do Spring MVC parecerem óbvios depois.

## 💡 Intuição (explicação simples)
Um template é uma **carta-modelo de mala direta**: "Prezado(a) ____, seu saldo é R$ ____". A gráfica (o servidor) pega a lista de clientes (o banco), preenche os campos de cada carta e **envia a carta pronta**. O Thymeleaf tem um truque simpático: o modelo é uma **página HTML válida** com dados de exemplo ("Ana Silva", "R$ 830,00"), que **abre normalmente no navegador** como protótipo; ao ser processado pelo servidor, os atributos `th:` **substituem** esses exemplos pelos dados reais. O designer e o dev trabalham no mesmo arquivo (os "*natural templates*").

## 🔬 Como funciona por dentro
```mermaid
sequenceDiagram
    participant B as Navegador
    participant S as PayflowServer (HttpServer)
    participant R as Repositórios JDBC
    participant T as Thymeleaf
    B->>S: GET /accounts/{id}  (Cookie: PAYFLOW_SESSION)
    S->>S: sessão → usuário? conta é dele?
    S->>R: statement(accountId, page, 5)
    R-->>S: List<LedgerEntry>
    S->>S: monta o modelo (Map) com EntryView formatado
    S->>T: render("statement", modelo)
    T-->>S: String HTML (valores escapados)
    S-->>B: 200 text/html; charset=utf-8
```
O servidor é o da J2.06 (`com.sun.net.httpserver`) e o acesso a dados é o da J3 (`JdbcAccountRepository`). **Nada de Spring ainda.** Na J5, o `@Controller` assume o papel de `PayflowServer.handle`, o `Model` o do `Map`, e os **mesmos templates** continuam valendo.

### SSR × página montada no navegador
| | Renderização no servidor (esta aula) | Montada no navegador (J4.05, Angular/React em J4.07) |
|---|---|---|
| Quem monta o HTML | O servidor, a cada requisição | O JavaScript, depois de baixar JSON |
| Primeira tela | Já vem completa | Vem "vazia" e é preenchida |
| Sem JavaScript | Funciona | Não funciona |
| Regras e dados sensíveis | Ficam no servidor | O JSON precisa expor o que a tela mostra |
| Interatividade rica | Cada ação recarrega a página (ou usa JS pontual) | Natural |
O PayFlow usa **os dois, de forma complementar**: páginas por SSR e um **pedacinho** de JavaScript (o "Mais antigos") que busca JSON.

### Expressões do Thymeleaf (as que usamos)
| Sintaxe | Significado | Exemplo |
|---|---|---|
| `${...}` | variável do **modelo** (OGNL no Thymeleaf standalone) | `${user.fullName}` |
| `@{...}` | URL (com contexto/parâmetros) | `@{/accounts/{id}(id=${a.id})}` ⚠️ só em contexto web (veja "Erros comuns") |
| `\|...\|` | substituição em literal (junta texto e variáveis) | `th:href="\|/accounts/${account.id}\|"` |
| `~{arquivo :: fragmento}` | inclui um **fragmento** de outro template | `~{fragments :: header}` |
| `#numbers`, `#lists`, `#strings` | objetos utilitários | `#numbers.formatDecimal(v,1,'POINT',2,'COMMA')` |

| Atributo | O que faz |
|---|---|
| `th:text` | troca o texto do elemento, **escapando** HTML |
| `th:utext` | troca **sem escapar** (perigoso) |
| `th:each="x : ${lista}"` | repete o elemento para cada item |
| `th:if` / `th:unless` | inclui/remove o elemento conforme a condição |
| `th:href`, `th:action`, `th:value` | calculam o atributo (`href`, `action`, `value`) |
| `th:classappend` | acrescenta classes CSS condicionalmente |
| `th:attr="a=${...}"` | define atributos arbitrários (valor `null` **remove** o atributo) |
| `th:replace` / `th:insert` | troca/insere o elemento por um **fragmento** |
| `th:fragment` | declara um trecho reutilizável |

### O que testamos no motor (Thymeleaf 3.1.7.RELEASE)
```text
th:text  com "<script>alert(1)</script>" -> <p>&lt;script&gt;alert(1)&lt;/script&gt;</p>
th:utext com "<script>alert(1)</script>" -> <p><script>alert(1)</script></p>      ← NÃO escapou
th:text="${x}" com x = null              -> <p></p>                               (o "padrão do designer" some)
th:value="${x}" com x = null             -> <input value="">
#numbers.formatDecimal(1234567.5,1,'POINT',2,'COMMA') -> 1.234.567,50
th:if  e th:each com lista vazia         -> <ul></ul><p>vazio</p>
```
O motor **escapa por padrão** o que entra por `th:text` e por `[[...]]`: é a **principal defesa contra XSS** em páginas de servidor. `th:utext` existe para HTML **seu**; com dado de usuário é uma vulnerabilidade.

### 3. O motor de templates (`Views`)
```java
package com.payflow.web;

import java.util.Locale;
import java.util.Map;
import org.thymeleaf.TemplateEngine;
import org.thymeleaf.context.Context;
import org.thymeleaf.templatemode.TemplateMode;
import org.thymeleaf.templateresolver.ClassLoaderTemplateResolver;

/** Thymeleaf "solto" (sem Spring): templates em src/main/resources/templates/*.html. */
final class Views {

    private static final Locale PT_BR = Locale.of("pt", "BR");
    private final TemplateEngine engine;

    Views(boolean cacheTemplates) {
        var resolver = new ClassLoaderTemplateResolver();
        resolver.setPrefix("templates/");
        resolver.setSuffix(".html");
        resolver.setTemplateMode(TemplateMode.HTML);
        resolver.setCharacterEncoding("UTF-8");
        resolver.setCacheable(cacheTemplates);
        engine = new TemplateEngine();
        engine.setTemplateResolver(resolver);
    }

    String render(String template, Map<String, Object> model) {
        var context = new Context(PT_BR);
        context.setVariables(model);
        return engine.process(template, context);
    }
}
```
- `ClassLoaderTemplateResolver` procura `templates/<nome>.html` no *classpath* (por isso os arquivos ficam em `src/main/resources`).
- `Context` com `Locale pt-BR`: define o idioma para formatações e mensagens que dependem dele (no painel, passamos os separadores de `#numbers.formatDecimal` explicitamente, então o resultado não depende do idioma da máquina).
- `setCacheable(false)` em desenvolvimento: edite o template, recarregue a página e veja. Em produção o cache fica **ligado**.

### 4. Sessão por cookie (`Sessions`)
```java
package com.payflow.web;

import com.payflow.db.User;
import java.security.SecureRandom;
import java.util.Base64;
import java.util.Map;
import java.util.Optional;
import java.util.concurrent.ConcurrentHashMap;

/** Sessões em memória: id aleatório (cookie) -> usuário. Some quando o servidor reinicia. */
final class Sessions {

    private final SecureRandom random = new SecureRandom();
    private final Map<String, User> byId = new ConcurrentHashMap<>();

    String create(User user) {
        byte[] bytes = new byte[32];                       // 256 bits: impossível de adivinhar
        random.nextBytes(bytes);
        String id = Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
        byId.put(id, user);
        return id;
    }

    Optional<User> userOf(String sessionId) {
        return sessionId == null ? Optional.empty() : Optional.ofNullable(byId.get(sessionId));
    }

    void destroy(String sessionId) {
        if (sessionId != null) {
            byId.remove(sessionId);
        }
    }
}
```
É a **sessão no servidor** da J2.04: o cookie guarda só um identificador aleatório de **256 bits** (`SecureRandom`, impossível de adivinhar) e o servidor guarda quem é o usuário. O cookie sai com `HttpOnly` (o JavaScript não lê) e `SameSite=Lax` (não vai em `POST` vindo de outro site). Limitações assumidas: a sessão está **só na memória** (some ao reiniciar; a J8 e o P2 mostram alternativas) e **não há expiração** nem `Secure` (precisa de HTTPS, J2.03).

### 5. O servidor do painel (`PayflowServer`)
```java
package com.payflow.web;

import com.payflow.db.Account;
import com.payflow.db.AccountUnavailableException;
import com.payflow.db.JdbcAccountRepository;
import com.payflow.db.JdbcUserRepository;
import com.payflow.db.LedgerEntry;
import com.payflow.db.User;
import com.sun.net.httpserver.Headers;
import com.sun.net.httpserver.HttpExchange;
import com.sun.net.httpserver.HttpServer;
import java.io.IOException;
import java.io.InputStream;
import java.math.BigDecimal;
import java.net.InetSocketAddress;
import java.net.URLDecoder;
import java.nio.charset.StandardCharsets;
import java.time.ZoneId;
import java.time.format.DateTimeFormatter;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.UUID;
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import javax.sql.DataSource;

/**
 * Painel web do PayFlow (J4): páginas HTML renderizadas no servidor com Thymeleaf,
 * mais um endpoint JSON para o JavaScript. Ainda sem Spring: a J5 troca este roteador
 * por Spring MVC e mantém os templates.
 */
public final class PayflowServer {

    static final int PAGE_SIZE = 5;
    private static final String COOKIE = "PAYFLOW_SESSION";
    private static final ZoneId ZONE = ZoneId.of("America/Sao_Paulo");
    private static final DateTimeFormatter DATE_TIME = DateTimeFormatter.ofPattern("dd/MM/yyyy HH:mm");
    private static final String UUID_RE = "([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})";
    private static final Pattern STATEMENT_PAGE = Pattern.compile("^/accounts/" + UUID_RE + "$");
    private static final Pattern DEPOSIT = Pattern.compile("^/accounts/" + UUID_RE + "/deposit$");
    private static final Pattern STATEMENT_API = Pattern.compile("^/api/accounts/" + UUID_RE + "/statement$");
    private static final Pattern STATIC_FILE = Pattern.compile("^/static/([a-z0-9.-]+\\.(css|js))$");

    private final JdbcUserRepository users;
    private final JdbcAccountRepository accounts;
    private final Sessions sessions = new Sessions();
    private final Views views;

    private PayflowServer(DataSource ds, boolean cacheTemplates) {
        this.users = new JdbcUserRepository(ds);
        this.accounts = new JdbcAccountRepository(ds);
        this.views = new Views(cacheTemplates);
    }

    /** Cria (sem iniciar) o servidor. Porta 0 = o sistema escolhe uma porta livre (útil em testes). */
    public static HttpServer create(DataSource ds, int port, boolean cacheTemplates) throws IOException {
        var app = new PayflowServer(ds, cacheTemplates);
        HttpServer server = HttpServer.create(new InetSocketAddress(port), 0);
        server.createContext("/", app::handle);
        return server;
    }

    // ---------------------------------------------------------------- roteamento

    private void handle(HttpExchange ex) throws IOException {
        try (ex) {
            String method = ex.getRequestMethod();
            String path = ex.getRequestURI().getPath();
            Matcher m;
            if (path.equals("/") && method.equals("GET")) {
                redirect(ex, "/accounts");
            } else if ((m = STATIC_FILE.matcher(path)).matches() && method.equals("GET")) {
                staticFile(ex, m.group(1));
            } else if (path.equals("/login") && method.equals("GET")) {
                html(ex, 200, views.render("login", model(null)));
            } else if (path.equals("/login") && method.equals("POST")) {
                login(ex);
            } else if (path.equals("/logout") && method.equals("POST")) {
                sessions.destroy(sessionId(ex));
                ex.getResponseHeaders().add("Set-Cookie", COOKIE + "=; Path=/; Max-Age=0; HttpOnly; SameSite=Lax");
                redirect(ex, "/login");
            } else if (path.equals("/accounts") && method.equals("GET")) {
                withUser(ex, false, user -> accountsPage(ex, user));
            } else if ((m = STATEMENT_PAGE.matcher(path)).matches() && method.equals("GET")) {
                UUID id = UUID.fromString(m.group(1));
                withUser(ex, false, user -> statementPage(ex, user, id, null, 200));
            } else if ((m = DEPOSIT.matcher(path)).matches() && method.equals("POST")) {
                UUID id = UUID.fromString(m.group(1));
                withUser(ex, false, user -> deposit(ex, user, id));
            } else if ((m = STATEMENT_API.matcher(path)).matches() && method.equals("GET")) {
                UUID id = UUID.fromString(m.group(1));
                withUser(ex, true, user -> statementJson(ex, user, id));
            } else {
                html(ex, 404, views.render("error", model(null, "title", "Página não encontrada",
                        "message", "O endereço " + path + " não existe.")));
            }
        } catch (RuntimeException e) {
            e.printStackTrace();
            html(ex, 500, views.render("error", model(null, "title", "Algo deu errado",
                    "message", "Não conseguimos concluir a operação. Tente de novo em instantes.")));
        }
    }

    private interface UserAction {
        void run(User user) throws IOException;
    }

    /** Exige sessão: sem ela, páginas redirecionam para /login e a API responde 401 em JSON. */
    private void withUser(HttpExchange ex, boolean api, UserAction action) throws IOException {
        Optional<User> user = sessions.userOf(sessionId(ex));
        if (user.isPresent()) {
            action.run(user.get());
        } else if (api) {
            json(ex, 401, Map.of("error", "not authenticated"));
        } else {
            redirect(ex, "/login");
        }
    }

    // ---------------------------------------------------------------- páginas

    private void login(HttpExchange ex) throws IOException {
        Map<String, String> form = readForm(ex);
        String email = form.getOrDefault("email", "").trim().toLowerCase();
        Optional<User> user = users.findByEmail(email);
        if (user.isEmpty()) {
            html(ex, 401, views.render("login", model(null, "error", "Não encontramos esse e-mail.", "email", email)));
            return;
        }
        String session = sessions.create(user.get());
        ex.getResponseHeaders().add("Set-Cookie", COOKIE + "=" + session + "; Path=/; HttpOnly; SameSite=Lax");
        redirect(ex, "/accounts");
    }

    private void accountsPage(HttpExchange ex, User user) throws IOException {
        html(ex, 200, views.render("accounts", model(user, "accounts", accounts.findByOwner(user.id()))));
    }

    private void statementPage(HttpExchange ex, User user, UUID accountId, String formError, int status)
            throws IOException {
        Optional<Account> account = ownedAccount(user, accountId);
        if (account.isEmpty()) {
            html(ex, 404, views.render("error", model(user, "title", "Conta não encontrada",
                    "message", "Não encontramos essa conta.")));
            return;
        }
        int page = intParam(ex, "page", 0, 0, 10_000);
        List<EntryView> entries = accounts.statement(accountId, page, PAGE_SIZE).stream().map(this::view).toList();
        boolean hasMore = !accounts.statement(accountId, page + 1, PAGE_SIZE).isEmpty();
        Map<String, Object> model = model(user, "account", account.get(), "entries", entries,
                "page", page, "hasMore", hasMore);
        if (formError != null) {
            model.put("formError", formError);
        }
        html(ex, status, views.render("statement", model));
    }

    private void deposit(HttpExchange ex, User user, UUID accountId) throws IOException {
        if (ownedAccount(user, accountId).isEmpty()) {
            statementPage(ex, user, accountId, null, 404);
            return;
        }
        String raw = readForm(ex).getOrDefault("amount", "").trim().replace(',', '.');
        try {
            BigDecimal amount = new BigDecimal(raw);
            accounts.deposit(accountId, amount);
            redirect(ex, "/accounts/" + accountId);       // Post/Redirect/Get: F5 não repete o depósito
        } catch (IllegalArgumentException e) {            // inclui NumberFormatException
            statementPage(ex, user, accountId, "Informe um valor positivo com até 2 casas decimais, como 25,90.", 400);
        } catch (AccountUnavailableException e) {
            statementPage(ex, user, accountId, "Esta conta não aceita depósitos agora.", 422);
        }
    }

    private void statementJson(HttpExchange ex, User user, UUID accountId) throws IOException {
        if (ownedAccount(user, accountId).isEmpty()) {
            json(ex, 404, Map.of("error", "account not found"));
            return;
        }
        int page = intParam(ex, "page", 0, 0, 10_000);
        List<Object> rows = new ArrayList<>();
        for (LedgerEntry e : accounts.statement(accountId, page, PAGE_SIZE)) {
            Map<String, Object> row = new LinkedHashMap<>();
            row.put("id", e.id().toString());
            row.put("type", e.type());
            row.put("transferId", e.transferId() == null ? null : e.transferId().toString());
            row.put("amount", e.amount().toPlainString());          // dinheiro como string (decisão 11)
            row.put("createdAt", e.createdAt().toInstant().toString());
            rows.add(row);
        }
        boolean hasMore = !accounts.statement(accountId, page + 1, PAGE_SIZE).isEmpty();
        json(ex, 200, Map.of("page", page, "hasMore", hasMore, "entries", rows));
    }

    /** Só devolve a conta se ela for do usuário da sessão; de outro dono = "não existe" (o IDOR é tema de J8). */
    private Optional<Account> ownedAccount(User user, UUID accountId) {
        return accounts.findById(accountId).filter(a -> a.ownerId().equals(user.id()));
    }

    // ---------------------------------------------------------------- modelo de visão

    /** O que o template precisa para uma linha do extrato — já formatado para quem lê. */
    public record EntryView(String label, boolean credit, BigDecimal amount, String when) { }

    private EntryView view(LedgerEntry e) {
        boolean credit = e.type().equals("CREDIT");
        String label = e.transferId() == null ? "Depósito"
                : credit ? "Transferência recebida" : "Transferência enviada";
        return new EntryView(label, credit, e.amount(), DATE_TIME.format(e.createdAt().atZoneSameInstant(ZONE)));
    }

    private static Map<String, Object> model(User user, Object... pairs) {
        Map<String, Object> m = new HashMap<>();
        m.put("user", user);
        for (int i = 0; i < pairs.length; i += 2) {
            m.put((String) pairs[i], pairs[i + 1]);
        }
        return m;
    }

    // ---------------------------------------------------------------- HTTP: auxiliares

    private static String sessionId(HttpExchange ex) {
        List<String> headers = ex.getRequestHeaders().get("Cookie");
        if (headers == null) {
            return null;
        }
        for (String header : headers) {
            for (String part : header.split(";")) {
                String[] kv = part.trim().split("=", 2);
                if (kv.length == 2 && kv[0].equals(COOKIE)) {
                    return kv[1];
                }
            }
        }
        return null;
    }

    private static Map<String, String> readForm(HttpExchange ex) throws IOException {
        String body = new String(ex.getRequestBody().readNBytes(16_384), StandardCharsets.UTF_8);
        Map<String, String> form = new HashMap<>();
        for (String pair : body.split("&")) {
            if (pair.isEmpty()) continue;
            String[] kv = pair.split("=", 2);
            form.put(URLDecoder.decode(kv[0], StandardCharsets.UTF_8),
                    kv.length == 2 ? URLDecoder.decode(kv[1], StandardCharsets.UTF_8) : "");
        }
        return form;
    }

    private static int intParam(HttpExchange ex, String name, int fallback, int min, int max) {
        String query = ex.getRequestURI().getRawQuery();
        if (query != null) {
            for (String pair : query.split("&")) {
                String[] kv = pair.split("=", 2);
                if (kv[0].equals(name) && kv.length == 2) {
                    try {
                        return Math.max(min, Math.min(max, Integer.parseInt(kv[1])));
                    } catch (NumberFormatException ignored) {
                        return fallback;
                    }
                }
            }
        }
        return fallback;
    }

    private static void html(HttpExchange ex, int status, String body) throws IOException {
        send(ex, status, "text/html; charset=utf-8", body.getBytes(StandardCharsets.UTF_8));
    }

    private static void json(HttpExchange ex, int status, Object body) throws IOException {
        send(ex, status, "application/json; charset=utf-8", JsonWriter.write(body).getBytes(StandardCharsets.UTF_8));
    }

    private static void redirect(HttpExchange ex, String location) throws IOException {
        ex.getResponseHeaders().add("Location", location);
        ex.sendResponseHeaders(303, -1);                      // 303 See Other: o navegador troca para GET
    }

    private static void staticFile(HttpExchange ex, String name) throws IOException {
        try (InputStream in = PayflowServer.class.getResourceAsStream("/static/" + name)) {
            if (in == null) {
                send(ex, 404, "text/plain; charset=utf-8", "not found".getBytes(StandardCharsets.UTF_8));
                return;
            }
            String type = name.endsWith(".css") ? "text/css; charset=utf-8" : "text/javascript; charset=utf-8";
            send(ex, 200, type, in.readAllBytes());
        }
    }

    private static void send(HttpExchange ex, int status, String contentType, byte[] body) throws IOException {
        Headers headers = ex.getResponseHeaders();
        headers.set("Content-Type", contentType);
        headers.set("X-Content-Type-Options", "nosniff");
        ex.sendResponseHeaders(status, body.length);
        ex.getResponseBody().write(body);
    }
}
```

Pontos para ler com calma:
- **Roteamento manual** (`handle`): cada rota é um `if` com método + caminho (com expressões regulares para o `UUID`). É o que o `@GetMapping`/`@PostMapping` fará por você na J5.
- **`withUser`**: sem sessão válida, páginas redirecionam a `/login` (**303**) e a API responde **401** em JSON (um `fetch` não deve receber uma página de login).
- **Post/Redirect/Get** (`redirect` com **303 See Other**): depois de `POST /login` e `POST .../deposit` bem-sucedidos o servidor **não** devolve HTML; manda o navegador fazer um `GET`. Assim, **F5 não repete o depósito** (testado).
- **Erros de formulário reexibem a página** com o status certo e a mensagem: **400** (valor inválido), **422** (regra de negócio: conta bloqueada), **401** (e-mail desconhecido), **404** (conta que não existe **ou** é de outra pessoa).
- **`ownedAccount`**: toda leitura de conta confere o dono. Uma conta de outro usuário é tratada como **inexistente (404)**: não confirma que ela existe. A proteção completa (**IDOR**, papéis) é o tema da J8.
- **`EntryView`**: o que a tela precisa, **já formatado** (rótulo, data em `America/Sao_Paulo`). O template não conhece `LedgerEntry`.
- **`hasMore`** faz uma consulta a mais (`statement(id, page + 1, 5)`): simples e correta; na J6 a paginação com `Page` traz o total em uma consulta só.
- Arquivos estáticos só passam pelo padrão `^/static/([a-z0-9.-]+\.(css|js))$`: sem `..`, sem barras (`/static/..%2fpom.xml` → 404, testado).
- Os **erros do servidor** viram uma página 500 genérica; o detalhe vai para o log (`printStackTrace` só no estudo; na J5, SLF4J).

```java
package com.payflow.web;

import java.util.List;
import java.util.Map;

/** Escritor de JSON mínimo (só String, boolean, int, List e Map) — o suficiente para J4. Na J5 o Jackson assume. */
final class JsonWriter {

    private JsonWriter() { }

    static String write(Object value) {
        StringBuilder sb = new StringBuilder();
        append(sb, value);
        return sb.toString();
    }

    private static void append(StringBuilder sb, Object v) {
        switch (v) {
            case null -> sb.append("null");
            case String s -> quote(sb, s);
            case Boolean b -> sb.append(b);
            case Integer i -> sb.append(i);
            case Map<?, ?> m -> {
                sb.append('{');
                boolean first = true;
                for (var e : m.entrySet()) {
                    if (!first) sb.append(',');
                    first = false;
                    quote(sb, String.valueOf(e.getKey()));
                    sb.append(':');
                    append(sb, e.getValue());
                }
                sb.append('}');
            }
            case List<?> l -> {
                sb.append('[');
                for (int i = 0; i < l.size(); i++) {
                    if (i > 0) sb.append(',');
                    append(sb, l.get(i));
                }
                sb.append(']');
            }
            default -> throw new IllegalArgumentException("unsupported: " + v.getClass());
        }
    }

    private static void quote(StringBuilder sb, String s) {
        sb.append('"');
        for (char c : s.toCharArray()) {
            switch (c) {
                case '"' -> sb.append("\\\"");
                case '\\' -> sb.append("\\\\");
                case '\n' -> sb.append("\\n");
                case '\r' -> sb.append("\\r");
                case '\t' -> sb.append("\\t");
                default -> {
                    if (c < 0x20) sb.append(String.format("\\u%04x", (int) c));
                    else sb.append(c);
                }
            }
        }
        sb.append('"');
    }
}
```

## 🧠 Pausa para lógica
O usuário envia o formulário de depósito e o servidor responde **200 com a página do extrato** (sem redirecionar). O usuário aperta F5. O que o navegador pergunta e o que acontece com o saldo se ele confirmar? Como o PRG resolve? E por que o status do erro de validação é **400** (e não 200) mesmo devolvendo uma página HTML?

<details><summary>Dica e solução</summary>

Dica: o `POST` é o que o F5 repete. Solução: o navegador avisa "Reenviar o formulário?"; ao confirmar, **repete o `POST`** e o depósito é feito **de novo** (dinheiro em dobro). Com PRG, a resposta ao `POST` é `303 Location: /accounts/ID`; o navegador faz um `GET`, e o F5 repete só o `GET` (inofensivo). O erro de validação responde **400** porque o **status** descreve o resultado para quem não é o olho humano (testes, monitoramento, `curl`, a J6): "a entrada estava errada". A página com a mensagem é só o corpo. (Boa prática: erro de formulário → mesmo `GET`/template com status 4xx; sucesso → 303.)
</details>

## ⚠️ Erros comuns e boas práticas de produção
- **Link `@{/...}` fora do Spring.** No Thymeleaf standalone (sem contexto web), `th:href="@{/accounts/{id}(id=${a.id})}"` falha com:
  ```text
  org.thymeleaf.exceptions.TemplateProcessingException: Link base "/accounts/{id}" cannot be context relative (/...) unless the context used for executing the engine implements the org.thymeleaf.context.IWebContext interface
  ```
  Por isso a aula usa `th:href="|/accounts/${account.id}|"`. No Spring MVC (J5), o contexto é web e o `@{...}` funciona (e acrescenta o *context path* da aplicação).
- **Propriedade com nome errado:** `${a.nome}` quando o campo é `fullName` →
  ```text
  Caused by: ognl.NoSuchPropertyException: ThymeLab$Account.nome
  ```
  (a mensagem encadeada final é a que importa; role o *stack trace* até o último `Caused by`, J0.06).
- **Objeto nulo na navegação:** `${u.fullName}` com `u` nulo → `Caused by: ognl.OgnlException: source is null for getProperty(null, "fullName")`. Use `${u?.fullName}` (navegação segura) ou `th:if="${u != null}"` (o PayFlow usa `th:if="${user != null}"` no cabeçalho).
- **Template inexistente:** `TemplateInputException: An error happened during template parsing (template: "templates/nope.html")` com `Caused by: java.io.FileNotFoundException: ClassLoader resource "templates/nope.html" could not be resolved`. Confira prefixo, sufixo e se o arquivo está em `src/main/resources` (e se você rodou `mvn compile` para copiá-lo a `target/classes`).
- **Fragmento inexistente:** `Error resolving fragment: "~{naoexiste :: x}": template or fragment could not be resolved`.
- **`java.net.BindException: Address already in use`:** já há algo na porta 8080 (outra instância do painel). Pare a anterior ou use `PORT=8081`.
- **`th:utext` com dado do usuário:** XSS. Use `th:text`.
- **Esquecer o PRG:** F5 repete o depósito.
- **Cache de templates ligado em desenvolvimento:** a página não reflete a edição. (E **desligado** em produção: processa o arquivo a cada requisição.)
- **Lógica de negócio no template:** o template só **apresenta**. Cálculos, regras e formatação de domínio ficam no Java (`EntryView`).
- **Login "provisório" em produção:** o painel desta aula **não verifica senha** (o `password_hash` do seed é falso). Fica restrito a desenvolvimento até a J8, com BCrypt e Spring Security.
- **Sessão sem expiração, sem `Secure`, sem proteção CSRF:** limitações conhecidas desta versão; a J8 trata de cada uma (`SameSite=Lax` já barra o pior caso do CSRF por `POST` cruzado).

<details><summary>Soluções de referência</summary>

1. (a) Escapa: `&lt;b&gt;` aparece como texto (testado com `<script>`). (b) O fragmento é como um método com parâmetros: `th:fragment="head(title)"` declara; `head('Entrar')` passa o valor, usado em `${title}`. (c) 404 não confirma a existência do recurso a quem não tem direito; 403 revelaria "existe, mas não é seu". (d) `302` é ambíguo (alguns clientes mantinham o método); `303 See Other` diz explicitamente "faça um GET no outro endereço" (MDN, Redirections).
2. Todo o código está nesta aula; os critérios acima são verificáveis com os `curl` e com `mvn test`. Para o XSS: `INSERT INTO users (email, full_name, password_hash) VALUES ('x@x.com', '<img src=x onerror=alert(1)>', 'x')`; login com `x@x.com`; o cabeçalho exibe o texto literal (o teste `unknownEmailIsRejectedAndTheOutputIsEscaped` cobre o caso do e-mail digitado).
3. A chave precisa ser **a mesma** se o usuário reenviar o mesmo formulário (duplo clique, F5, retry): é assim que o `UNIQUE (idempotency_key)` (J3) barra a segunda transferência. Se o servidor gerasse a chave no `POST`, cada reenvio seria "uma operação nova". (Esboço, não executado.)
</details>

## 🎤 Na entrevista
- **O que é o Thymeleaf e o que são "natural templates"?** Um motor de templates HTML do lado do servidor cujos arquivos continuam sendo HTML válido, abertos direto no navegador como protótipo; atributos `th:*` substituem o conteúdo de exemplo ao processar.
- **`th:text` ou `th:utext`?** `th:text` escapa o HTML (seguro por padrão); `th:utext` não escapa e só serve para HTML confiável. Dado de usuário com `utext` é XSS.
- **O que é o padrão Post/Redirect/Get e por quê?** Após um `POST` que altera estado, responder com um redirecionamento (303) para um `GET`, evitando reenvio ao recarregar e duplicação da operação.
- **SSR ou SPA?** SSR: primeira tela completa, funciona sem JS, regras no servidor, simples; SPA: interatividade rica e uma API reutilizável, com mais JavaScript e mais superfície no cliente. A escolha depende do produto e do time; é comum combinar.
- **Por que uma conta de outro usuário devolve 404 e não 403?** Para não confirmar que o recurso existe; e a verificação de dono tem de estar no servidor, em **toda** rota (IDOR, J8).
