# payflow

Sistema de pagamentos pronto para produção, usado por milhares de usuários.

Tecnologias: Java, Spring, Kafka, Kubernetes, AWS, microsserviços.

## Como rodar
Configure o banco e rode a aplicação pela IDE.

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/payflow
spring.datasource.password=payflow123
```
